# Contact Patch — магазин шин, дисков и тормозов (US + EU)

> «Contact Patch» — рабочее название. Меняется в одном месте: `lib/company.ts` → `tradingName`.

Интернет-магазин американской компании для двух рынков: **США** (`/us`, USD) и **Европа** (`/eu`, EUR с НДС). У каждого рынка свои цены, свой ассортимент, свои политики и свой товарный фид для Google Merchant Center.

Архитектура повторяет проект 3DJools, который прошёл проверки Google Merchant Center, Google Ads и Google Business Profile.

Журнал всех изменений и примечаний — [`docs/ARCHIVE.md`](docs/ARCHIVE.md).

## Как посетитель попадает в свой магазин

Адрес любой страницы: `/<магазин>/<язык>/...`, например `/us/es/tires`, `/eu/de/policies/returns`.

| Магазин | Языки |
| --- | --- |
| `/us` | `en` (английский), `es` (испанский для США) |
| `/eu` | `en`, `de`, `fr`, `it`, `es` (испанский Испании), `nl` |

`proxy.ts` перенаправляет **только неполные адреса** (`/`, `/tires`, `/eu`, `/eu/tires`, `/us/de`):

1. **Магазин:** cookie `cp_market` (посетитель сам выбрал US/EU) → страна из `x-vercel-ip-country` (США и территории → `/us`; ЕС-27 и остальная Европа → `/eu`) → иначе `/us`.
2. **Язык:** cookie `cp_lang` (выбран переключателем) → заголовок браузера `Accept-Language` → иначе `en`. Если языка нет в этом магазине (например `/us/de`) — подставляется доступный.

Полные адреса (`/us/en/...`, `/eu/fr/...`) **никогда не перенаправляются** — Googlebot ходит из США и должен видеть все магазины и языки.

Если посетитель из США открыл EU-магазин (или наоборот), сверху показывается плашка с предложением перейти (`components/layout/geo-banner.tsx`). Переключатели языка и магазина — в верхней полосе шапки. Корзины раздельные по магазинам (`cp-cart-us-v1`, `cp-cart-eu-v1`), общие для всех языков магазина.

SEO (`lib/seo.ts`): у каждой страницы canonical на свой язык и полный набор hreflang — `en-US`, `es-US`, `en`, `de`, `fr`, `it`, `es`, `nl`, `x-default` — корень (редирект по гео и языку). `<html lang>` ставится по магазину и языку.

## Переводы

- Настройки языков (какие есть в каком магазине, hreflang, локаль для дат и цен) — `lib/i18n/config.ts`.
- Строки интерфейса — словари `lib/i18n/dictionaries/*.ts` (`en`, `es-419` для США, `es`, `de`, `fr`, `it`, `nl`). Ключи во всех словарях одинаковые — TypeScript не даст пропустить строку.
- Тексты политик: английский — `lib/legal/us.ts`, `lib/legal/eu.ts`; переводы — `lib/legal/us-es.ts`, `lib/legal/eu-de.ts`, `eu-fr.ts`, `eu-it.ts`, `eu-es.ts`, `eu-nl.ts`. **Факты и цифры менять во всех файлах рынка одновременно**; сами цифры берутся из `lib/policies.ts`.
- Форма отказа (EU) на каждом языке повторяет официальный текст Annex I(B) директивы 2011/83/EU для этого языка.
- Тексты товаров (названия, описания) пока на английском во всех языках — переводить вместе с реальным каталогом.

- `/[market]/[lang]` — главная
- `/[market]/[lang]/tires`, `/wheels`, `/brakes` — каталог с фильтрами
- `/[market]/[lang]/product/[slug]` — карточка товара

- `/sitemap.xml`, `/robots.txt`

## Политики — отдельно для каждого рынка

**США:** shipping, returns (30 дней), warranty (гарантия производителя, Magnuson-Moss), payments, terms, privacy (CCPA/CPRA, сигнал Global Privacy Control), privacy-choices («Do Not Sell or Share»).

**ЕС:** shipping (с НДС, без пошлин, DDP), returns (14 дней, модельный текст Annex I(A) директивы 2011/83/EU, оценка стоимости возврата крупногабарита), withdrawal-form (Annex I(B)), warranty (2 года, директива 2019/771), payments, terms (кнопка «Order with obligation to pay»), privacy (GDPR, представитель по ст. 27), cookies, legal-notice.

Ссылку на платформу ODR ЕС не ставить — она закрыта 20.07.2025.

Все цифры (стоимость доставки, сроки, окно возврата) берутся **только** из `lib/policies.ts`. Их же читают страницы, JSON-LD и фиды — поэтому они всегда совпадают.

## Товарные фиды

Один фид на каждый язык магазина:

- `/feeds/google-us-en.xml`, `/feeds/google-us-es.xml` — USD, страна США
- `/feeds/google-eu-en.xml`, `-de`, `-fr`, `-it`, `-es`, `-nl` — EUR с НДС, страны ЕС

В Merchant Center каждый подключается **отдельным источником данных** с языком контента этого фида и меткой фида `US` или `EU`. Ссылки на товары в фиде ведут на страницу того же языка. Старых адресов `google-us.xml` / `google-eu.xml` больше нет.

Правила:
- Категории Google: шины `6093`, диски `6090`, тормоза `2977`.
- GTIN и MPN **не выдумывать**. Нет кода → `identifier_exists=no`.
- Шины в EU: EU-этикетка (регламент 2020/740, EPREL). Шины в US: UTQG.
- Товар продаётся на рынке, только если у него есть offer для этого рынка.
- Товар исключается из фида, если: демо (`sample: true`), нет фото, предзаказ без даты, EU-шина без этикетки, неверный GTIN. Логика — `feedExclusion()` в `lib/feeds/google.ts`.

## Согласие на cookies

`components/legal/consent-defaults.tsx` выставляет Google Consent Mode v2 (по умолчанию всё `denied`, для EU плюс `ads_data_redaction`) и **только после этого** подгружает тег Google Analytics — если задан `NEXT_PUBLIC_GA_ID`.

Любые будущие теги (GTM, пиксели) подключать через этот же компонент, а не отдельным `<script>`.

## Переменные окружения

| Переменная | Назначение |
| --- | --- |
| `NEXT_PUBLIC_SITE_URL` | Основной домен (для канонических ссылок, фидов, sitemap) |
| `NEXT_PUBLIC_GA_ID` | ID Google Analytics 4 (необязательно) |
